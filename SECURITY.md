# Security Policy

ProbJax is experimental research software and is not intended for
security-critical or production use. Only the latest code on `main` receives
security fixes.

Please report suspected vulnerabilities privately through
[GitHub's security advisory form](https://github.com/mackelab/probjax/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Reports are handled on a best-effort basis. Include reproduction steps,
affected versions or commits, and the potential impact when possible.
